How to use วิธีใช้หน้านี้

หาหัวข้อ → ดู canvas → เปิดแท็บโค้ดและกฎ ก่อนเขียนหน้าใหม่

4 ขั้น

  1. เลือกหัวข้อทางซ้าย — แบ่งหมวดตามหน้าที่: พื้นฐาน (สี ตัวอักษร ไอคอน) · ปุ่ม · ฟอร์ม · แสดงข้อมูล · หน้าต่างซ้อน · โครงหน้า · หน้าที่มากับระบบ login · คลิกชื่อหมวดเพื่อยุบ/ขยาย · พิมพ์ค้นหาได้ · จอมือถือเลือกจากเมนูด้านบน
  2. ดู canvas — กรอบที่ใช้สีจริงของ kit · ปุ่ม สว่าง/มืด สลับธีมเฉพาะ canvas · ปุ่ม Mobile บีบกรอบเหลือ 390px เพื่อดูหน้าตาบนมือถือ
  3. เปิดแท็บใต้ canvas — ตัวอย่าง = ทุก variant ที่ kit มีให้ ไม่มีของที่ kit ไม่ได้ส่งมา · ใช้ยังไง = โค้ดพร้อม path import จริงจาก kit กดคัดลอกได้ · ทำ/อย่าทำ = อ่านก่อนเขียนหน้าใหม่
  4. ไปหัวข้อถัดไป — ปุ่ม ก่อนหน้า/ถัดไป ท้ายทุกหัวข้อ เรียงตามหมวด
ข้อจำกัดของหน้านี้ เป็นภาพจำลองด้วย HTML/CSS ไม่ใช่ React จริง · ปุ่ม Mobile จำลองจอเล็กกว่า 640px (breakpoint sm) — ของจริงบางส่วนขึ้นที่จอ ≥ 1024px (lg) เช่น จำนวนรายการ แถวต่อหน้า ปุ่มหน้าแรก/สุดท้าย และ hero หน้า login · สีทุกตัวตรงกับ globals.tokens.css (สคริปต์ scripts/check-preview-tokens.mjs ตรวจทุกรอบ)

ห้ากฎที่กันของเพี้ยน 90% ของคอมเมนต์ตอน review งาน UI

ทำ
  • ตารางใช้ DataTable กลาง และส่ง id ทุกครั้ง
  • สถานะใช้ StatusBadge — สี + ไอคอนคู่กันเสมอ
  • วันที่และตัวเลขผ่าน lib/format.ts ที่เดียว
  • ปุ่มใช้ variant + size มาตรฐาน · เพิ่ม variant ใหม่ต้องบันทึกเป็นมติ
  • ปุ่มไอคอนล้วนในแถวตารางใช้ IconAction (label บังคับ)
อย่าทำ
  • เขียน <table> เอง — ค้นหา/เรียง/แบ่งหน้าไม่เหมือนหน้าอื่น
  • ใส่สีสถานะเอง — หลุดชุดสีกลาง คนตาบอดสีแยกไม่ออก
  • format วันที่ในหน้า — server เป็น UTC วันเลื่อน · พ.ศ./ค.ศ. สลับ
  • ปรับขนาด/สีปุ่มด้วย className — density หลุดมาตรฐาน
  • ปุ่มไอคอนเปล่า ๆ — screen reader อ่านไม่ออก ไม่มี tooltip
