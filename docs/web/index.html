ใช้งาน 3 แบบ

พิมพ์เป็นภาษาคนได้เลย ตัวช่วยที่ตรงกับงานจะเริ่มทำงานเอง

1

มีโปรเจคอยู่แล้ว

ตรวจของเดิมก่อน ถามคำถามชุดเดียว แล้วติดตั้งครบตามลำดับ ท้ายงานได้เอกสารส่งทีม admin

ทำให้โปรเจคนี้ deploy ได้ตามมาตรฐานบริษัทหน่อย
2

มีแต่โฟลเดอร์ requirement

อ่านเอกสารแล้วสรุปเป็น brief ภาษาไทยแยกตาม feature พร้อมคำถามที่ต้องถาม stakeholder

อ่าน requirement แล้วทำ brief แยกเป็น feature
3

ทำ feature ทุกวัน

กฎมาตรฐานโค้ดและกับดัก production โหลดเองเมื่อแตะไฟล์ จบงานด้วย /ugt-handoff

สร้างหน้ารายการคำขอลาพร้อมตัวกรอง

ลำดับที่ full-setup ติดตั้งให้

สลับลำดับไม่ได้ เพราะแต่ละขั้นพึ่งขั้นก่อนหน้า

  • DatabasePrisma + SQL Server
  • Test-LintVitest · ESLint · husky
  • Designธีม · UI kit · DESIGN.md
  • AuthSSO / AD / รหัสผ่าน · สิทธิ์ · หน้า admin
  • CI/CDJenkins · SonarQube · Docker
+ Mail (ถ้าต้องส่งเมล)+ Upload (ถ้าต้องแนบไฟล์)+ ไฟล์ harness: CLAUDE.md · .claude/ · docs/project-context/
