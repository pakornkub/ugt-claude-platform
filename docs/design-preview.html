ทุกสี ทุกระยะ ทุกขนาดในหน้านี้ดึงมาจากไฟล์ token จริงที่ ugt-nextjs-design-setup ติดตั้งลงโปรเจค (globals.tokens.css) — ไม่ใช่ภาพ mockup ที่วาดขึ้นใหม่ สิ่งที่คุณเห็นคือสิ่งที่ทีมจะได้ตั้งแต่หน้าแรก

shadcn/ui · style base-mira (Base UI) Inter + Noto Sans Thai lucide icons เท่านั้น Light + Dark ทุกโทเคน ผ่าน WCAG AA ทุกคู่สี

หน้านี้เป็นตัวอย่างเชิงภาพเพื่อการตัดสินใจ — ของจริงคือ React component ที่ติดตั้งลงโปรเจค (components/ui/*) ข้อตกลงฉบับเต็มของแต่ละโปรเจคอยู่ใน docs/DESIGN.md

5 · สถานะของข้อมูล

ว่าง กำลังโหลด ผิดพลาด — มีหน้าตามาตรฐานให้แล้ว

ไม่ต้องเขียน if-loading เองทุกหน้า ทุกสถานะมี component กลางรออยู่ ผลคือผู้ใช้เจอ หน้าตาเดียวกันไม่ว่าจะอยู่ส่วนไหนของระบบ

Loading · Empty · Error
Skeleton — โครงเดิม ไม่กระตุก
ยังไม่มีใบลาในช่วงนี้ ลองขยายช่วงวันที่ หรือสร้างรายการใหม่
ไม่สามารถโหลดข้อมูลได้ กรุณาลองใหม่อีกครั้ง
Error ระดับหน้าอยู่บนสุดของการ์ด · ระดับช่องอยู่ใต้ช่องนั้น
6 · กฎที่กันของเพี้ยน

สิ่งที่ระบบไม่ยอมให้ทำ

ห้าข้อนี้คือ 90% ของคอมเมนต์ตอน review งาน UI — หลังติดตั้ง กฎพวกนี้จะถูกโหลดให้ AI อ่านเอง ทุกครั้งที่แตะไฟล์หน้าจอ และบางข้อมีสคริปต์ตรวจซ้ำให้ด้วย

✕ เขียนตารางเอง
แต่ละหน้าได้ค้นหา/เรียง/แบ่งหน้าไม่เหมือนกัน และไม่มีใครจำการตั้งค่าของผู้ใช้ได้
✓ ใช้ DataTable กลาง
ได้ชุดความสามารถครบเท่ากันทุกหน้า และต้องส่ง id เสมอ ไม่งั้นสคริปต์ตรวจจะฟ้อง
✕ ใส่สีสถานะเอง
สีหลุดจากชุดกลาง คนตาบอดสีแยกไม่ออก เพราะมีแต่สีไม่มีไอคอน
✓ ใช้ StatusBadge
บังคับสี + ไอคอนคู่กัน สีมาจากโทเคนที่ผ่าน contrast แล้ว
✕ format วันที่ตรงหน้าจอ
server เป็น UTC แล้ววันเลื่อน · พ.ศ./ค.ศ. สลับกันตาม เครื่องผู้ใช้
✓ ผ่าน lib/format.ts ที่เดียว
จอเป็น DD/MM/YYYY เสมอ · ไฟล์ export เป็น ISO กัน Excel สลับวัน-เดือน
✕ ปรับขนาด/สีปุ่มเอง
ความหนาแน่นหลุดมาตรฐาน แต่ละหน้าปุ่มคนละขนาด
✓ ใช้ variant + size มาตรฐาน
เพิ่ม variant ใหม่ได้ แต่ต้องบันทึกเป็นมติในข้อตกลง
✕ ปุ่มไอคอนล้วนเปล่า ๆ
screen reader อ่านไม่ออก และไม่มี tooltip ผู้ใช้เดาเอง
✓ ใช้ IconAction
บังคับใส่ label ซึ่งกลายเป็นทั้ง aria-label และ tooltip

แล้วสิ่งเหล่านี้ถูกรักษาไว้ยังไง

ตอนติดตั้ง ระบบจะถามไม่กี่ข้อ (สีแบรนด์? โหมดมืด? เมนูข้างหรือบน?) แล้วเขียน ข้อตกลงทั้งหมดลง docs/DESIGN.md ของโปรเจค พร้อมกฎที่ทำให้ AI อ่านข้อตกลงเองทุกครั้งก่อนแตะไฟล์หน้าจอ — หน้าที่ทำเดือนหน้าจึงยังหน้าตาเหมือนหน้าแรก และมีสคริปต์ตรวจซ้ำอีกชั้นสำหรับข้อที่ตรวจด้วยเครื่องได้ (คู่สี contrast, ตารางที่ลืมใส่ id)
