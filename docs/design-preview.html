8 · สถานะและ feedback

ว่าง กำลังโหลด ผิดพลาด — มีหน้าตามาตรฐานให้แล้ว

ไม่ต้องเขียน if-loading เองทุกหน้า — สถานะข้อมูลผ่าน ui/query-state · Skeleton สำหรับโครง · spinner ในปุ่ม (พร้อม disabled) สำหรับ action · Empty ใช้ ui/empty ทุกกรณี ทั้งตารางว่าง ไม่มีสิทธิ์ และ 404

ป้าย (Badge) — มี component 2 ตัว ใช้ 5 กรณี

StatusBadge สร้างจาก Badge variant="outline" อีกที ส่วนคำว่า "chip" คือวิธีใช้ Badge แบบหนึ่ง ไม่ใช่ component ใหม่ · หลักแยกที่จำง่าย: มีไอคอน + บอกสถานะ = StatusBadge · ที่เหลือทั้งหมด = Badge

5 กรณีของป้าย
1 · สถานะ → StatusBadge (tone + ไอคอนบังคับ)
อนุมัติแล้ว รออนุมัติ ไม่อนุมัติ ขอยกเลิก ระบบสร้าง ฉบับร่าง
2 · ป้ายกำกับ/ตัวระบุ → Badge outline (ข้อความล้วน ห้ามสีสถานะ)
ผู้อนุมัติระดับต้น ระบบ ลาพักร้อน
3 · ตัวเลขนับ → Badge + tabular-nums
5 12 99+ เป็น 0 ให้ซ่อน ไม่แสดงเลข 0 · เกิน 99 แสดง 99+
4 · chip ตัวกรองที่กดปิดได้ → Badge secondary + ปุ่ม ✕
สถานะ: รออนุมัติ หน่วยงาน: บัญชี
5 · ป้ายสีที่ต้องไม่มีไอคอน → Badge outline + TONE_STYLES
IN OUT ใช้ token ชุดเดียวกับ StatusBadge ห้ามประกาศสีใหม่

ทั้ง 5 กรณีเป็น rounded-full — ไม่อยู่ในสเกล radius 4 ระดับ

12 · กฎที่กันของเพี้ยน

สิ่งที่ระบบไม่ยอมให้ทำ

ห้าข้อนี้คือ 90% ของคอมเมนต์ตอน review งาน UI — หลังติดตั้ง กฎพวกนี้ถูกโหลดให้ AI อ่านเองทุกครั้งที่แตะไฟล์หน้าจอ และบางข้อมีสคริปต์ตรวจซ้ำให้ด้วย

✕ เขียนตารางเอง

แต่ละหน้าได้ค้นหา/เรียง/แบ่งหน้าไม่เหมือนกัน และไม่มีใครจำการตั้งค่าของผู้ใช้ได้

✓ ใช้ DataTable กลาง

ได้ชุดความสามารถครบเท่ากันทุกหน้า และต้องส่ง id เสมอ ไม่งั้นสคริปต์ตรวจจะฟ้อง

✕ ใส่สีสถานะเอง

สีหลุดจากชุดกลาง คนตาบอดสีแยกไม่ออกเพราะมีแต่สีไม่มีไอคอน

✓ ใช้ StatusBadge

บังคับสี + ไอคอนคู่กัน สีมาจากโทเคนที่ผ่าน contrast แล้ว

✕ format วันที่ตรงหน้าจอ

server เป็น UTC แล้ววันเลื่อน · พ.ศ./ค.ศ. สลับกันตามเครื่องผู้ใช้

✓ ผ่าน lib/format.ts ที่เดียว

จอเป็น DD/MM/YYYY เสมอ · ไฟล์ export เป็น ISO กัน Excel สลับวัน-เดือน

✕ ปรับขนาด/สีปุ่มเอง

ความหนาแน่นหลุดมาตรฐาน แต่ละหน้าปุ่มคนละขนาด

✓ ใช้ variant + size มาตรฐาน

เพิ่ม variant ใหม่ได้ แต่ต้องบันทึกเป็นมติในข้อตกลง

✕ ปุ่มไอคอนล้วนเปล่า ๆ

screen reader อ่านไม่ออก และไม่มี tooltip ผู้ใช้เดาเอง

✓ ใช้ IconAction
